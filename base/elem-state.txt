ez itt még pont jó lenne, de stateful elementek esetén könnyű megfeledkezni a cache-elésről

II. Imperatív létrehozása:

private static final Color DEFAULT_BACKGROUND = Color.parse("#F9F986");
private static final Color PRESSED_BACKGROUND = Color.parse("#E9E974");

private final ScalarProp<Boolean> pressed = new OVal<>(false);

@Content private final Box box = new Box(
        new Padding(Insets.all(em(.5)), //
                row( //
                        new TextElement("Teammate and Opponent Preferences"), //
                        Align.right(arrow)
                ) //
        ) //
);

@RepeatedInit
void updateArrow() {
    arrow.text.set(isOpen.get() ? "\u2191" : "\u2193");
    box.background(pressed.get() ? PRESSED_BACKGROUND : DEFAULT_BACKGROUND);
}

ezt @RepeatedInit nélkül megoldani kétféleképpen lehet:
 - ha buildereket generálunk amik fogadnak ReadableScalarPropt, de ahhoz meg annotation processor kéne
 - implementáljuk TextElementDesc és BoxDesc interface-eket, ami egész értelmes megoldás
   lenne, de Javában borzalmas sok kód kell anonymous inner classhoz
